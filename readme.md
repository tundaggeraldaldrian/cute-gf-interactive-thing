A small interactive page. One button runs away when you try to click it, the other doesn't.

## Try it

Open `for-her.html` in a browser.

## How it works

- Two buttons: Yes and No
- Yes dodges every time you try to click it
- No grows a bit bigger each time, with a new message
- Clicking No shows the ending screen with a heart animation

## Files

- `for-her.html` — everything, HTML/CSS/JS in one file

## Customize

Open the file and edit:
- The question text
- The messages
- The colors (top of the `<style>` block)
